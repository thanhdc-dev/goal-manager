# Models – Conventions

## Quy tắc cơ bản
- Chỉ chứa `interface` và `type`, KHÔNG có class hay logic
- Mọi date field là `string` định dạng ISO (`YYYY-MM-DD` hoặc ISO string đầy đủ), KHÔNG dùng `Date` object
- Không import từ nơi khác ngoài model khác trong cùng folder

## Các types quan trọng

```ts
type AccumulationType = 'daily' | 'monthly';
type ProgressStatus = 'ahead' | 'on-track' | 'behind' | 'completed' | 'expired';
type ValueType = 'integer' | 'decimal';
```

## GoalStats
- `progress` và `expectedProgress`: giá trị từ 0–100 (phần trăm)
- `remainingPeriods`: số ngày nếu `accumulationType === 'daily'`, số tháng nếu `'monthly'`
- `requiredPerPeriod`: nếu `valueType === 'integer'` thì đã được `Math.ceil()`, nếu `'decimal'` thì giữ nguyên
- `milestones`: mảng 4 phần tử tương ứng 25%, 50%, 75%, 100%
- `isExpired`: true nếu ngày hôm nay > endDate của goal
