# Services – Conventions

## Dependency Injection
Luôn dùng `inject()` function, KHÔNG dùng constructor injection.

```ts
// ✅ Đúng
export class MyService {
  private goalService = inject(GoalService);
}

// ❌ Sai
export class MyService {
  constructor(private goalService: GoalService) {}
}
```

## GoalService
- Storage key: `gm_goals`
- `goals` là readonly signal, không mutate trực tiếp
- `activeGoals` là computed, tự động lọc goal chưa hết hạn (now <= endDate)
- `create()` tự gán `key` (crypto.randomUUID()) và `createdAt` (ISO string)
- Định danh công khai là `key`; KHÔNG có `id` ở client (backend tự sinh `id` nội bộ)
- `getByKey(key)` → `Goal | undefined`

## LogService
- Storage key: `gm_logs`
- `logs` là readonly signal
- `getSignalByGoalKey(goalKey)` → `Signal<Log[]>` — API duy nhất để lấy logs theo goal (reactive); gọi trong component/computed hoặc đọc ngay bằng `getSignalByGoalKey(key)()`. KHÔNG thêm lại hàm snapshot `getByGoalKey()`
- `create()` tự gán `key` và `createdAt`
- Log tham chiếu goal qua `goalKey`

## CalculationService
- Pure computation, không có side effects, không gọi localStorage
- Có internal cache theo `goalKey + logsHash` để tránh tính lại khi data không đổi
- `computeStats(goal, logs)` → `GoalStats` — luôn gọi hàm này thay vì tự tính
- `getPredictionMessage(goal, stats)` → chuỗi tiếng Việt mô tả dự đoán tiến độ
- `accumulationType === 'daily'` → tính theo ngày; `'monthly'` → tính theo tháng
